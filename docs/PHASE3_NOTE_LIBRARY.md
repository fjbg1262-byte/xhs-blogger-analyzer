# Phase 3 笔记库与导出

日期：2026-11-01。对应 [开发顺序](product/DEVELOPMENT_PLAN.md) 第 5 节 Phase 3。

## 目标

把真实采集结果做成日常可用的数据工具：筛选、排序、分页、多选、导出，且**导出条数与页面筛选一致**。

## 服务端筛选与分页

`GET /api/workspace/tasks/{id}` 接受以下参数，页面、tab 计数和导出共用同一套规则：

| 参数 | 说明 |
|---|---|
| `q` | 标题 / 正文 / 标签包含关键词 |
| `type` | `图文`、`视频`，空表示全部 |
| `after` / `before` | 发布时间范围，`YYYY-MM-DD`，缺日期的不计入范围 |
| `incomplete` | 只返回正文或详情未成功的笔记 |
| `ids` | 逗号分隔的笔记 ID，用于「导出选中」和按选中过滤 |
| `sort` | `engagement`、`likes`、`collected`、`comments`、`shares`、`published`、`list_order` |
| `page` / `page_size` | 默认 1 / 50，页大小上限 100 |

返回 `notes` 的同时返回 `total`、`page`、`pages` 和 `facets`（全部 / 图文 / 视频 / 未完成），所以 tab 上的数字也是服务端算的，不会和翻页后的列表打架。

## 导出一致性

`GET /api/workspace/tasks/{id}/export` 接受同一组筛选参数：

- `format=csv|xlsx|feishu`，默认 xlsx；飞书版只输出干净的表头与数据行。
- 先按 `q / type / after / before / incomplete / ids` 过滤，再排序、再截断 `top`，最后生成文件。
- 因此「页面显示 60 篇图文」与「导出 60 篇图文」是同一条路径，不存在前端一套、导出另一套。

## 多选与批量导出

- 表格首列可勾选，表头复选框切换当前页；选中后出现「已选择 N 篇 / 清空 / 导出选中 Excel / 导出选中飞书包」。
- 批量导出把选中的 `ids` 传给同一个导出接口，行数与选中数一致。

## 原始数据备份

`GET /api/workspace/tasks/{task_id}/backup` 直接返回该任务的 `dataset.json`（约 380KB / 100 篇），文件名 `xhs-task-<id>-backup.json`。

- 页面按钮「下载原始数据」。
- 它没有经过任何导出整形，是排错和迁移用的原始依据。

## 性能

`dataset.json` 与其统计结果按 `(路径, mtime, size)` 缓存，最多 6 个任务；筛选、翻页、轮询都不会重复解析 400KB JSON。补采写回文件后 mtime 变化，缓存自动失效。

## 已验证（2026-11-01）

- `tests/test_workspace_api.py`：**10 项通过**，其中新增筛选/分页与导出一致性：图文 60 篇、导出 CSV 行数 = 筛选结果 + 表头、`ids` 导出 2 行、日期与未完成过滤。
- 真实数据（任务 #8，100 篇）：全部 100 / 2 页；图文 60；搜索 `AI` 85 篇；`after=2026-09-01` 24 篇；`ids` 2 篇；飞书导出 115KB；原始备份 380,902 字节。
- 无头 Edge（`tests/browser/workspace-smoke.cjs`）：分页 50+50、「图文」tab 共 60 篇、搜索共 85 篇、勾选后出现「已选择 1 篇」、四个导出按钮、详情按需加载、新建采集校验，全部通过且无运行时报错。

## 还没做
