# Phase 6 多账号对比

日期：2026-11-03。对应 [开发顺序](product/DEVELOPMENT_PLAN.md) 第 8 节 Phase 6。

## 一期做法

`/workspace` 增加第三个标签「账号对比」：选 2–5 个已采集账号，用同一套八维看差异。

- 账号来源：`GET /api/workspace/tasks` 里每个账号的最新一次采集（同一账号多次采集不会重复列出）。
- 对比接口：`GET /api/workspace/compare?task_ids=8,7`，2–5 个任务，不足或越界返回中文提示。
- 所有数值都来自各自的 `dataset.json`，**不调用模型**；「下一步」和一周计划是规则推导，并在页面底部标明。

## 八维对比行

| 行 | 取值 |
|---|---|
| 账号定位 | Top 标签 + 图文/视频占比 |
| 内容方向 | Top 3 标签 |
| 选题结构 | Top 标签出现次数 · 覆盖标签数 |
| 标题与封面 | 平均标题字数 · 含数字比例 · 缺封面篇数 |
| 互动表现 | 单篇中位数 · 头部占比 · 均值 |
| 发布节奏 | 月均篇数 · 最近发布时间 |
| 标签与搜索 | Top 3 标签及次数 |
| 下一步动作 | 基于最佳形式与 Top 标签的规则建议 |

## 结论与计划

- 「值得借鉴」：比较单篇中位数；差距在一个数量级内给百分比，超过则说明差距明显并提醒样本量。
- 「不要照搬」：两个账号的最佳内容形式不同时提示先小样本测试。
- 「共同主题」：两个账号 Top 标签的交集，说明可以互相参考但保留各自风格。
- 一周计划：5 个动作，基于笔记数最多的账号的 Top 标签和最佳形式生成。
- 边界：只用公开互动与已采集字段，不含浏览、曝光、粉丝或转化；建议是规则推导，不是模型结论。

## 已知限制

1. 同一账号存在多条账号记录时（重复采集同一主页）按名称加 `#id` 区分，不会自动合并。
2. 对比只取每个账号最新一次采集；想比较同账号不同批次时目前做不到。
3. 结论是规则推导，不做因果判断；后续接入模型时应保留同样的边界。
