# 当前实现与可验收状态

更新日期：2026-10-31。应用版本 **0.3.0-beta.4**，浏览器扩展 **0.4.0**。

## 结论

“采集整理 → 笔记库 → 固定批次 AI 解读与 3 个创作草稿 → 人工复核 → HTML/PDF 下载”的前后端主链路已经接通，离线回归、前端生产构建和源码模式自检通过。

当前可以进入受控试用。真实 `deepseek-flash` 已在一批100篇、100篇有正文的本机采集数据上完成一次生成并通过证据校验；仍不能把“真实平台长期稳定”和“跨领域模型质量”写成已通过。正式售卖前仍需覆盖更多账号，并用实际 Excel/WPS 和飞书完成端到端验收。

## 已实现

| 模块 | 当前状态 |
|---|---|
| 主页采集 | 最多100篇、分页保护、逐篇详情、网络有限重试、访问受限停止、停止保留已有数据 |
| 数据整理 | 28列统一数据集、空值与0区分、原子保存、按发布时间/互动/中位数筛选 |
| 导出 | Excel双工作表、UTF-8 CSV、飞书单表导入版；公式注入保护、链接和正文保留 |
| AI 配置 | 卖家按本机账号配置 OpenAI/Claude/兼容接口；Key 不解密返回、不出现在导出 |
| AI 生成 | 客户目标、八维解读、3个选题、每题2个标题、开头、3至6段大纲、测试与复盘 |
| 深度分析 | 公开互动总量、均值/中位数/分位、内容形式强度、Top20%集中度、标题语言信号、标签频次、月度节奏和头部内容榜 |
| 客户报告 | 咨询式18页级A4结构：封面、核心发现、内容组合、头部表现、战略、标题信号、八维、3个创作案、7天计划、证据索引 |
| 证据约束 | 只能引用本次实际发送的标题/正文原句；未知ID、伪造引用、重复证据会被拒绝 |
| 结果隔离 | 笔记库变化、生成规则升级、进程中断后旧结果不能确认或导出 |
| 待复核交付 | 未确认只能预览；人工确认后才开放正式 HTML/PDF；目标改变后必须重新生成 |
| 安全边界 | 不发送 Cookie/Key/图片/评论；不承诺曝光、受众画像、因果、涨粉、SEO或商业结果 |
| 打包 | 新构建入口包含前端、扩展、源码快照、文件校验、自检和运行数据扫描 |

## 最近补齐

- 报告规则版本升级为 `evidence-delivery-4`，旧规则结果自动标记为过期。
- 模型配置增加 provider、URL、字段长度和本机/HTTPS 校验；保存改为原子写入。
- 设置接口不再回显 Key 的前后片段。
- 客户修改目标但尚未重生成时，前端禁止复核、确认和下载旧稿。
- 真实100篇批次暴露输出截断后，增加“首次过长则分段生成八维和草稿”的保底路径；首次校验失败时把具体原因带入唯一一次修复。
- 新增四段内容战略判断、公开互动指标体系和客户报告图表；明确区分公开互动与浏览/曝光/ROI，不补造不可获得的数据。
- 新增咨询式移动端友好总览，将核心发现、形式差异、集中度、标题信号、主题和头部内容前置。
- 重做PDF分页与视觉验收，修正窄屏样式污染打印、空白续页、维度卡和标题信号溢出。
- 打包自检增加 AI schema、分析路由、前端构建、Excel 导出和运行时依赖检查。
- 产品文案、版本号、扩展提示和打包说明统一到 0.3.0-beta.4。
