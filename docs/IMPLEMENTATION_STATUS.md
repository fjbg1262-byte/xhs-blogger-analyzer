# 当前实现与可验收状态

更新日期：2026-11-01。应用版本 **0.3.0-beta.6**，浏览器扩展 **0.4.0**。

## 结论

“采集整理 → 笔记库 → 固定批次 AI 解读与 3 个创作草稿 → 人工复核 → HTML/PDF 下载”的前后端主链路已经接通，离线回归、前端生产构建和源码模式自检通过。

Phase 1 的纯前端 Demo 已经成形，并成为本地程序入口：启动后首页就是 Demo，`?page=` 可把任一页面单独打开给评审。Demo 用模拟数据覆盖首页采集进度、笔记库表格/封面、单篇详情、账号八维、2 至 5 个账号对标、飞书交付、采集记录和设置，点击验收脚本 29 项全部通过。

当前可以进入受控试用。真实 `deepseek-flash` 已在一批100篇、100篇有正文的本机采集数据上完成一次生成并通过证据校验；仍不能把“真实平台长期稳定”和“跨领域模型质量”写成已通过。正式售卖前仍需覆盖更多账号，并用实际 Excel/WPS 和飞书完成端到端验收。

## 最近补齐

- Phase 1 Demo：`/demo` 成为本地程序入口，首页直达；`?page=` 深链接，导航与地址栏双向同步，刷新不丢当前页。
- Demo 采集进度补齐已读取、详情完成、正文成功、标签成功四项计数，以及“停止采集 / 继续处理未完成笔记 / 保留下载”。
- Demo 笔记库补齐互动较高分类、时间范围与“只看正文”“只看未完成”筛选、按评论/分享排序；详情抽屉显示未完成原因、来源链接，并可加入选题或账号对比。
- Demo 八维页补齐笔记数、单篇中位数、最近发布指标，维度卡可展开下一步建议，3 个选题补开头和正文大纲。
- Demo 对标页支持 2 至 5 个账号动态列宽，新增一周内容计划；采集记录补完成时间、未完成原因和备份下载。
- 无头 Edge 点击验收脚本扩展到 29 项，覆盖深链接、筛选、对比列宽、失败原因和截图。
- 报告规则版本升级为 `evidence-delivery-4`，旧规则结果自动标记为过期。
- 模型配置增加 provider、URL、字段长度和本机/HTTPS 校验；保存改为原子写入。
- 设置接口不再回显 Key 的前后片段。
- 客户修改目标但尚未重生成时，前端禁止复核、确认和下载旧稿。
- 真实100篇批次暴露输出截断后，增加“首次过长则分段生成八维和草稿”的保底路径；首次校验失败时把具体原因带入唯一一次修复。
- 20篇以上批次改为默认分段生成：八维/战略和选题/草稿分别调用、分别校验、分别修复，避免一份局部错误导致整份作废。
- AI失败不再提示用户补充正文或更换模型；前端明确说明采集和表格不受影响，并提供“重试生成”按钮。
- 任务状态记录所属进程，避免备用实例或并发轮询把另一进程正在运行的报告误判为中断。
- 新增四段内容战略判断、公开互动指标体系和客户报告图表；明确区分公开互动与浏览/曝光/ROI，不补造不可获得的数据。
- 新增咨询式移动端友好总览，将核心发现、形式差异、集中度、标题信号、主题和头部内容前置。
- 重做PDF分页与视觉验收，修正窄屏样式污染打印、空白续页、维度卡和标题信号溢出。
- 打包自检增加 AI schema、分析路由、前端构建、Excel 导出和运行时依赖检查。
- 产品文案、版本号、扩展提示和打包说明统一到 0.3.0-beta.6。
