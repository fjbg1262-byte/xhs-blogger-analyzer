# Phase 4 飞书导入 2.0

日期：2026-11-01。对应 [开发顺序](product/DEVELOPMENT_PLAN.md) 第 6 节 Phase 4。

## 目标

把「一张 28 列的大表」升级成用户第一次导入就能看懂的飞书多维表格：账号、全部笔记、图文、视频、选题、采集记录各一张工作表，字段干净、类型可映射，并带一份独立的导入说明。

## 工作簿结构

`GET /api/workspace/tasks/{id}/export?format=feishu` 生成 `workspace-<id>-feishu.xlsx`，工作表顺序：

| 工作表 | 行数（100 篇真实数据） | 内容 |
|---|---|---|
| 账号总览 | 1 行数据 | 账号、主页链接、笔记数、图文、视频、公开互动、单篇中位数、Top20% 贡献、最近发布、采集时间、任务状态 |
| 全部笔记 | 100 行 | 28 列统一契约，与 CSV 导出同源 |
| 图文笔记 | 60 行 | 同一批数据按类型拆分 |
| 视频笔记 | 40 行 | 同上 |
| 选题清单 | 10 行 | 按公开互动排序的候选选题：序号、选题、来源笔记 ID、笔记链接、类型、互动、建议角度、状态（候选） |
| 采集记录 | 1 行 | 任务 ID、账号、目标/实际、正文成功、未完成、开始/完成时间、状态、未完成原因 |
| 导入说明 | 14 条 | 导入三步、字段类型建议、各表含义、缺失值与口径说明 |

说明单独成表，不会混进数据行；「全部笔记」等表只有表头和记录。

## 字段类型

| 列 | 单元格类型 | 飞书建议类型 |
|---|---|---|
| 发布时间 / 采集时间 | Excel 日期（yyyy-mm-dd / yyyy-mm-dd hh:mm） | 日期 |
| 点赞数 / 收藏数 / 评论数 / 分享数 | 数字（千分位格式） | 数字 |
| 正文 | 文本（自动换行） | 多行文本 |
| 标签 / 图片链接 | 单元格内换行 | 多行文本 |
| 笔记链接 / 封面链接 / 主页链接 | 超链接 | 超链接 |
| 其余 | 文本 | 文本 |

## Excel 备份

`format=xlsx` 生成 `笔记库 + 账号总览 + 采集说明` 三张表，用于本地留档和 Excel/WPS 核对，与飞书包共用同一套写表逻辑。

## 仍需人工验收

1. **真实飞书多维表格导入一次**：本机没有用户飞书账号，无法自动验收；需要按「导入说明」三步在飞书里各导入一张表，确认日期/数字/多行文本/超链接四种类型。
2. **导入后排序**：按账号、类型、互动排序需要飞书侧操作，脚本无法代替。
3. **大量数据**：100 篇导出为秒级；上千篇时需要评估飞书单表导入上限。
