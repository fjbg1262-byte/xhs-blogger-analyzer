# Phase 1 前端验收记录

依据：[开发顺序](product/DEVELOPMENT_PLAN.md) 第 3 节 Phase 1，以及 [PRD](product/PRD.md) 第 5 章页面结构。
验收对象：`frontend/src/views/ProductDemoView.vue`（本地程序入口 `/demo`）。
日期：2026-11-01。版本：应用 `0.3.0-beta.7`，浏览器扩展 `0.4.0`。

## 结论

Phase 1 的页面、交互和点击预算全部通过：**功能验收 33/33**，**点击验收 34/34**。
1366×768、1280×800、1440×900 三种宽度下 9 个页面均无横向溢出；首屏可见采集入口；正文段落没有超过 160 字的大段说明。

验收不是人工目测，而是脚本执行：`node tests/browser/acceptance.cjs`（33 项）与 `node tests/browser/demo-smoke.cjs`（34 项）。

首次运行时 27/33，暴露出 6 个真实缺项（列表缺分享与来源列、首页缺导出状态、飞书页不能选账号、分析页缺图文占比与最近发布、选题缺一周执行顺序、对比页缺数据量提示），本轮已全部补齐后复跑通过。

## 有意偏离与未覆盖

1. **采集进度做成首页内嵌面板**，不是独立页面：从首页到飞书少一次跳转，Phase 2 接真实任务时可独立成页。
2. **Excel 备份在 Demo 里用 CSV 代替**：真实 Excel/WPS 导出属于 Phase 3（笔记库与导出），PRD 5.4 的 Excel 要求留到接真实数据时验收。
3. **飞书页只能选账号，不能勾选具体笔记子集**：笔记库已支持多选并跳转飞书页，实际按选中笔记生成属于 Phase 3。
4. **批量链接入口只有按钮**：单篇链接导入（PRD 流程 D）属于 Phase 3。
5. **没有做手机端适配**：Phase 1 只要求桌面与非超宽笔记本，手机端在商品化阶段再处理。
6. **对比页的「值得借鉴/不要照搬」是固定示例文案**：接真实八维后按账号生成，属于 Phase 6。

## 复跑方式

```powershell
# 1. 启动前端预览（或直接运行打包后的本地程序）
cd frontend; npm run build; npm run preview -- --port 4173

# 2. 功能验收 33 项
node tests/browser/acceptance.cjs

# 3. 点击验收 34 项
node tests/browser/demo-smoke.cjs

# 4. 截图复核（输出到 data/tasks/verification/demo-shots）
node tests/browser/demo-shots.cjs
```

也可以用 `$env:DEMO_BASE_URL="http://127.0.0.1:8123"` 指向打包后的本地程序，两组脚本都支持。
