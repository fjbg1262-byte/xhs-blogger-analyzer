# 内容整理与 AI 交付 0.3：产品与交付边界

确认日期：2026-10-31。应用版本 0.3.0-beta.7。

## 产品形态

Windows 本地服务（EXE）＋Chrome/Edge 扩展＋本地网页工作台。用户在已登录浏览器打开主页，点“整理当前主页”，自动打开笔记库。也支持在笔记库粘贴主页链接并使用已保存登录状态。

基础采集、整理和表格导出不需要模型。卖家可配置自己的模型 API，在固定笔记批次上生成客户交付；客户不配置 Key。API 调用会把本批公开标题、标签、互动数字、最多36篇正文摘录和客户目标发送给所选服务商。

输出最多100条主页接口可访问的笔记，包含置顶。主页顺序由平台返回，不能声称是全账号按时间排序后严格最新100篇。完成后可按发布时间排序；发布时间没有返回就留空。少于100篇时交付实际条数，不填充假数据。

## 交付字段与结构

一行一篇笔记，笔记ID唯一。按以下顺序排列28列：

标题、发布时间、点赞数、收藏数、评论数、分享数、内容类型、笔记链接、封面链接、正文、标签、图片链接、视频链接、博主昵称、博主ID、笔记ID、置顶、详情采集状态、正文采集情况、标签采集情况、缺失字段、采集说明、采集时间、互动数据来源、计数精度、点赞相对中位数、主页返回顺序、主页链接。

- Excel：笔记库＋采集说明；数字和日期使用原生单元格类型；冻结前两列及标题，提供筛选、换行、可点击链接。
- CSV：UTF-8 BOM，保留中文、换行、引号及完整正文；公式样式的原文加文本保护前缀。
- 飞书导入版：一个工作表、第一行字段名，其余为笔记；不包含合并单元格/说明行，方便导入多维表格。
- 网页：查看任务进度、搜索标题/正文/标签、按互动数/时间排序、时间范围、不低于点赞中位数、当前排序Top20。导出应用相同筛选。
- 空白=未获取；0=真实返回零。没有正文/没有标签与未获取分开。万/千缩写换算需标注精度。中位数统计包含0，基准为0或未知时倍数留空。
- 笔记链接保留平台返回的笔记访问参数，不是登录 Cookie；链接仍可能过期或要求浏览者登录。不会导出登录 Cookie、模型密钥或内部运行信息。
- 正文不进行AI改写或清洗。Excel单格上限32767字符，超长内容用CSV或本地dataset.json；原始数据不被截断。

## 采集边界

按页请求，每页最多30；达到100、末页、重复游标、没有新增、10页保护上限时停止。网络暂时失败最多重试2次。逐篇低频补齐详情（1.5秒间隔），不只抽30篇。登录失效/访问受限即停；连续3篇详情失败即停补采。默认900秒任务预算；在途请求受SDK请求超时限制，停止不会强杀进行中的网络请求。

每页、每篇详情后原子保存dataset.json。失败、停止和重启均保留已获取数据，部分完成允许导出。再次完整采集需新建任务；本版不提供跨任务断点续采。

本版不交付：评论正文、私信、受众画像、真实曝光阅读、真实转化、粉丝历史、批量媒体文件、OCR/视频转写、飞书自动同步。提供媒体 URL（可能过期），飞书 URL 不等于附件。旧版报告代码保留用于历史数据兼容，不纳入新主流程。

## AI 内容交付

- 客户先填写本次目标。目标至少5字、最多1200字，只影响本次 AI 生成。
- AI 工作台使用整批笔记，不受表格筛选影响；至少需要5篇不同笔记。正文预算最多36篇，交替选取高赞、低赞、中段、较新和主页顺序样本，每篇最多1600字；全部笔记的标题、标签和已知互动数字可参与。
- 输出固定包含8个解读维度、3个不同选题；每个选题含2个不同标题、读者问题、开头草稿、3至6段大纲、测试和复盘方式。
- 客户报告先给出公开互动总览、集中度、内容形式、标题语言、主题标签和头部内容，再呈现四段内容战略与八维诊断；所有指标都附带口径和因果边界。
- PDF采用分页咨询报告结构，包含封面、核心发现、内容组合、头部表现、内容战略、标题信号、八维诊断、3个完整创作案、7天计划和完整证据索引。
- 每个解读发现和创作草稿至少带1条证据。证据必须来自本次发送数据的真实标题或正文原句，笔记ID必须在允许范围内。引用未知ID、伪造原句、仅存在于未发送正文的内容会被拒绝。
- 八维必须唯一且完整；优先结论必须指向有证据的发现；资料不足时必须明确降级，不得凑结论。
- 20篇以上批次默认分成“八维解读与内容战略”和“三个选题与创作草稿”两次生成；每段最多自动修复一次。失败不会清除采集数据和表格，用户无需补充正文，只需直接重试。
- 客户目标、笔记库内容或报告生成规则变化时，已有结果过期，不能确认或导出。运行中断后也不会把半成品当作完成品。
- 报告先进入待复核状态。未确认只能预览草稿；人工确认后才开放正式 HTML/PDF。修改目标但未重新生成时，旧稿不能继续确认或下载。
- HTML/PDF只含客户可见解读、原文证据、资料限制和创作草稿，不含 API Key、Cookie、内部路径、请求体或日志。
- 不声称模型分析过图片或视频，不估算曝光/阅读/转化，不把相关性写成因果，不承诺流量、涨粉、搜索排名或商业结果。

## 成功标准

有数据时能直接导出使用；故障时说明停止原因及缺失情况，不以0冒充缺失、不丢前页成功结果。对有足够公开笔记且平台正常返回的账号，最多采集100条并逐篇尝试详情。

自动化测试用于验证调用规则、证据约束和导出正确性；真实平台稳定性需要实际登录环境验收，模型质量需要真实有效 Key 验收。均不能仅凭离线测试或模拟输出承诺。当前标为测试版。
