# 小红书内容整理与 AI 交付 · 0.3.0-beta.7

1. 将整个压缩包解压到固定目录，不要只拖出EXE。
2. 双击 `XHS-Organizer.exe`，保持窗口开启。服务只监听本机127.0.0.1:8000。
3. 在Edge或Chrome的扩展管理页加载本包的 `browser-extension` 文件夹。开发机建议固定加载项目根目录的同名文件夹，之后使用“重新加载”更新。
4. 在同一个浏览器登录小红书并打开目标博主主页，点击扩展“整理当前主页”。
5. 在笔记库等待采集，按需筛选，下载Excel、CSV或飞书导入版。
6. 飞书多维表格选择“导入Excel”，选飞书导入版文件。ID建议设为文本，互动数为数字，时间为日期，链接为超链接，正文为多行文本。这里只导入表格，不同步到飞书、不上传图片附件。

如果没有安装扩展，也可以在本地网页注册一个本机账号，在设置中保存登录状态，再回到笔记库输入主页链接。浏览器扩展会自动连接本地账号，无需手工注册。

最多100篇，含置顶，按照平台返回的主页顺序选取；不是全账号历史库。不满100篇按实际条数交付。空白是未获取，0是返回零。若出现部分完成，已采集行仍然可以下载。媒体只提供链接，失效时回笔记原文查看。

停止：在任务页点击“停止并保留已有数据”，等待在途请求结束。退出程序可关闭EXE控制台。若提示旧版占用8000端口，请先关闭旧版服务，不要反复打开多个版本。

## 配置卖家的 AI

1. 进入“设置”中的“LLM 配置”。
2. 选择 OpenAI、Claude 或其他兼容服务，填写你自己的 API Key；自定义服务还要填写 HTTPS API 地址和模型名称。
3. 保存后回到笔记库。配置只保存在本机运行数据目录，不写入交付包，也不会随 Excel/CSV/报告导出。
4. 打开已采集记录，在“内容交付工作台”填写客户目标。至少需要5篇不同笔记。
5. 勾选“同意将本批公开文字与目标发送至模型服务商”，生成后等待解读和草稿完成。可能产生模型费用。

模型只接收本批笔记的标题、标签、互动数字和最多36篇、每篇最多1600字的正文摘录；不发送 Cookie、API Key、图片或评论正文。目标变化后必须重新生成。引用不存在、原句不匹配或套用未发送正文的输出会被系统拒绝，不会进入可下载报告。

## 复核与交付

工作台提供“3个选题与草稿”“八维解读”“原始依据”三个视图。逐条核对原句、另一种解释和资料限制，确认没有虚构经历、效果或商业结论后，勾选人工复核并“确认交付”。

确认前只能预览草稿；确认后可下载网页版或 PDF。PDF需要本机安装 Edge 或 Chrome。导出只包含客户可见内容，不包含 API Key、Cookie、内部路径或运行日志。

AI 输出是工作底稿，不是平台官方数据，也不保证流量、涨粉、搜索排名或成交。图片、视频、评论正文、曝光、转化和粉丝历史均未分析。

运行数据保存在Windows本地应用数据目录的 `XHSOrganizer/0.2` 下（开发源码默认仍在项目data目录，可用 `XHS_APP_HOME` 指定位置）。这是为兼容已有数据保留的目录名，不是产品版本。不要向他人发送运行数据；分享原始干净ZIP。交付包包含 `SOURCE_MANIFEST.json` 和 `checksums.sha256`。
