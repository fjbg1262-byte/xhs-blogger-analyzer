# 小红书内容采集与账号对标工具 PRD

## 1. 产品定义

一款面向小红书创作者、运营和代运营团队的 Windows 本地工具，配合浏览器插件使用。

用户打开一个博主主页，或者提供一批笔记链接后，工具负责：

1. 采集可访问的公开笔记。
2. 整理成可搜索、可筛选、可导出的笔记库。
3. 生成飞书多维表格导入包，最终支持直接写入飞书。
4. 对单个账号做八维分析。
5. 选择多个账号做同维度对比，给出选题和运营建议。

产品的核心不是长报告，而是：

**内容采集 + 飞书交付 + 账号对标八维分析**

## 2. 产品卖点

对用户最直接的价值：

- 不再逐篇复制标题、正文、标签和互动数据。
- 100篇公开笔记可以在一次任务中完成整理。
- 图文、视频和账号分开查看，不混在一起。
- 表格和封面卡片两种方式浏览。
- 一键生成飞书可导入文件。
- 多个账号放在同一套八维框架里比较。
- AI只负责把结论和方案写清楚，不替代采集结果。

不做以下承诺：

- 不保证平台所有历史笔记都能采到。
- 不提供真实浏览量、搜索排名、粉丝增长、订单或转化。
- 不保证按某个标题写法就获得流量。
- 不提供私密内容、私信或后台数据。

## 3. 用户角色

### 内容创作者

想分析同类账号、找选题、比较标题和内容形式，希望结果能直接放进飞书。

### 内容运营

需要持续采集多个博主、整理对标素材、快速筛选和导出，关注效率和统一格式。

### 品牌与代运营团队

需要按客户保存多个账号、统一八维分析、输出对比结论和下一阶段选题。

## 4. 产品形态

### 浏览器插件

插件是轻入口，只做三件事：

- 识别当前小红书博主主页。
- 检查登录状态和本地工具状态。
- 点击“整理当前主页”启动任务。

插件不显示复杂分析结果。

### Windows 本地工具

本地工具是完整工作台，提供：

- 账号和链接采集。
- 图文/视频笔记库。
- 搜索、筛选、排序。
- Excel/CSV/飞书文件下载。
- 飞书目标配置和同步。
- 单账号八维分析。
- 多账号对比。
- AI选题与标题建议。

所有运行数据默认保存在本机。

## 5. 页面结构

### 5.1 首页

首页直接展示“开始采集”，不做长篇产品介绍。

推荐布局：

- 顶部：产品名、账号头像、设置。
- 左侧导航：首页、笔记库、账号分析、账号对比、飞书交付、采集记录、设置。
- 主区域上方：主页链接输入框、采集按钮、链接采集入口。
- 主区域中部：最近采集的账号卡片。
- 主区域下方：最近任务、数据条数、正文成功数、导出状态。

用户第一次打开就能知道：

1. 从哪里开始采集。
2. 采完的数据在哪里。
3. 如何导出或进入飞书。

### 5.2 采集任务页

显示：

- 当前账号。
- 已读取笔记数。
- 已完成详情数。
- 正文成功数。
- 标签成功数。
- 当前步骤。
- 停止按钮。

任务完成后，提供三个直接入口：

- 查看笔记库。
- 下载飞书文件。
- 开始账号分析。

失败或部分完成时：

- 明确显示未完成原因。
- 保留下载入口。
- 提供“继续处理未完成笔记”，不要求重新跑全部数据。

### 5.3 笔记库

这是产品主页面。

#### 顶部

- 账号名称与主页链接。
- 总笔记数。
- 图文数、视频数。
- 互动总数与单篇中位数。
- 最近采集时间。

#### 视图

- 表格视图：适合筛选、排序和批量操作。
- 封面视图：适合快速浏览内容主题。

#### 分类

- 全部笔记。
- 图文笔记。
- 视频笔记。
- 互动较高。
- 已收藏/已标记。
- 未完成采集。

#### 列表字段

- 封面。
- 标题。
- 发布时间。
- 内容类型。
- 点赞。
- 收藏。
- 评论。
- 分享。
- 标签。
- 来源链接。
- 采集状态。

#### 筛选

- 搜索标题、正文和标签。
- 按图文/视频筛选。
- 按时间范围筛选。
- 按互动数排序。
- 按收藏、评论或分享排序。
- 只看已抓到正文的笔记。
- 只看未完成采集的笔记。

#### 单篇详情

点击笔记后，在右侧打开详情：

- 封面。
- 完整标题和正文。
- 标签。
- 互动数据。
- 图片或视频链接。
- 来源笔记链接。
- 可加入选题清单。
- 可加入账号对比。

### 5.4 飞书交付页

首屏只做三件事：

1. 选择要交付的账号或笔记。
2. 选择飞书模板。
3. 生成或同步。

#### 第一版

- 一键下载飞书多维表格导入包。
- 同时生成 Excel 备份。
- 页面内展示本次包含的数据表和张数。
- 提供 3 步导入说明。

建议输出以下数据表：

1. 账号总览。
2. 全部笔记。
3. 图文笔记。
4. 视频笔记。
5. 选题清单。
6. 采集记录。

#### 第二版

- 配置用户自己的飞书目标。
- 选择 Base、数据表和字段。
- 首次同步。
- 后续只新增新笔记或更新变化的数据。
- 显示成功、重复、未完成数量。

飞书页面的最终效果应接近截图中的工作台：左侧多表、右侧按账号/图文/视频查看，笔记有封面、标题、互动和来源链接。

竞品截图保存在 [competitor-screenshots](competitor-screenshots/)。

### 5.5 账号分析

单账号分析结果直接回答业务问题。

页面顶部显示：

- 账号名称。
- 笔记数。
- 互动总量。
- 单篇互动中位数。
- 图文/视频占比。
- 最近发布时间。

下方固定为八维分析。

#### 八维定义

1. **账号定位**
   - 账号主要在讲什么。
   - 用户通常为什么关注或收藏。

2. **内容方向**
   - 当前内容由哪些主题组成。
   - 哪些方向数量最多、互动最好。

3. **选题结构**
   - 常见选题类型。
   - 哪些选题可以持续做。
   - 哪些只是单篇偶然表现好。

4. **标题与封面**
   - 常见标题写法。
   - 数字、问句、反差、清单等表达的使用情况。
   - 封面的可见特征。

5. **互动表现**
   - 点赞、收藏、评论、分享的结构。
   - 哪些内容更容易被收藏或讨论。
   - 不计算浏览量或互动率。

6. **发布节奏**
   - 发布时间分布。
   - 每月内容量。
   - 不同月份的内容类型变化。

7. **标签与搜索**
   - 高频标签。
   - 标签与内容的对应关系。
   - 不声称标签带来搜索流量。

8. **下一步建议**
   - 3个原创选题。
   - 每个选题提供2个标题、开头和正文大纲。
   - 给出一周执行顺序和复盘指标。

页面只展示结论、数据、原因、建议和必要的短句，保持业务语言。

### 5.6 账号对比

用户选择2至5个账号后，在同一套八维里比较：

- 定位差异。
- 内容方向差异。
- 选题密度。
- 标题和封面差异。
- 互动结构。
- 发布节奏。
- 标签差异。
- 可借鉴动作。

页面结构：

- 顶部账号选择与对比按钮。
- 第一行账号摘要卡。
- 第二行八维横向表格。
- 第三行“值得借鉴”和“不要照搬”。
- 第四行根据目标生成的内容计划。

对比结论必须写成业务动作，例如：

- “A账号连续做教程，收藏占比更高。”
- “B账号靠目的地清单获得高收藏，但内容数量较少。”
- “建议A补一类清单内容，不直接复制B的标题。”

对比结论直接写成下一步可执行的动作。

### 5.7 采集记录

用普通任务列表表达：

- 账号。
- 开始时间。
- 完成时间。
- 目标数量。
- 实际数量。
- 正文成功数量。
- 未完成原因。
- 备份文件。
- 查看笔记库。

采集记录只承担任务记录职责，不再增加额外页面。

### 5.8 设置

- 小红书登录状态管理。
- AI模型配置。
- 飞书配置。
- 数据目录。
- 版本与更新。

## 6. 典型使用流程

### 流程 A：采一个账号并交给飞书

1. 打开博主主页。
2. 点插件“整理当前主页”。
3. 等待任务完成。
4. 在笔记库检查图文、视频和缺失项。
5. 点击“飞书交付”。
6. 下载飞书导入包。
7. 在飞书导入多维表格。

### 流程 B：做一个账号的八维分析

1. 进入账号分析。
2. 查看八维数据和结论。
3. 选择要执行的3个选题。
4. 下载分析结果或写入飞书。

### 流程 C：对比多个账号

1. 选择2至5个已采集账号。
2. 点击“开始对比”。
3. 查看八维横向结果。
4. 选择可借鉴内容。
5. 生成下一周选题计划。

### 流程 D：单篇链接导入

1. 在首页粘贴一条或多条公开链接。
2. 系统去重并预览数量。
3. 采集后进入笔记库。
4. 可加入现有账号或独立导出。

## 7. 飞书导入后的呈现

用户导入后应看到：

- 左侧有账号、全部笔记、图文、视频、选题、采集记录。
- 每条笔记有封面、标题、正文、标签、互动和来源链接。
- 可以按账号分组。
- 可以按互动排序。
- 可以筛选未完成采集。
- 可以标记是否已用于选题。

第一版以文件导入为主；直接同步在采集和前端 Demo 验证后开发。

## 8. UI原则

- 首先像工作台，不像报告。
- 数据表、封面图和操作按钮优先。
- 页面主色和视觉风格待更多参考图确认。
- 表格信息密度高，但可以通过筛选和分组降低阅读负担。
- AI页面只展示用户要的业务结论和建议。
- 不用长段落代替可比较的字段。
- 所有界面文案使用直接、可执行的中文。

## 9. 首期范围

必须有：

- 当前插件主页采集。
- 图文/视频笔记库。
- 表格和封面视图。
- Excel/CSV/飞书导入包。
- 单账号八维分析。
- 3个原创选题。
- 采集记录和未完成原因。

暂不包含：

- 多平台采集。
- 自动发布。
- 平台评论全文。
- 私信和后台数据。
- 自动保证爆款。
- 复杂团队权限。

## 10. 产品成功标准

1. 用户打开工具后能直接找到“采集”。
2. 采完后第一眼能看到笔记数量和图文/视频数据。
3. 飞书文件下载和导入操作不超过3步。
4. 单账号八维分析不出现难懂的报告语言。
5. 多账号对比能直接回答“接下来做什么”。
6. AI失败不影响采集库、筛选和导出。
7. 用户愿意把它当作每天使用的采集与对比工具，而不是偶尔生成报告的网站。
