# 竞品拆解与可借鉴思路

更新日期：2026-10-31。

## 1. 证据边界

本文依据用户提供的商品页截图分析。截图能确认商品文案、界面结构和展示字段，但不能确认其后台技术、真实稳定性、实际模型效果或销量代表性。

截图中的价格、销量和促销只代表截图时点：

## 2. 竞品在卖什么

竞品表面在卖“爆款拆解 Skill”，实际销售的是一套连续工作流：

1. 用户提供公开笔记链接、视频链接或博主主页。
2. 系统提取标题、封面、正文、标签、公开互动和媒体信息。
3. 对图文或视频做结构化拆解。
4. 将原始数据、分析结果、附件和来源链接写入飞书多维表格。
5. 生成 Excel 备份、去重记录和失败原因。
6. 用户在一个可持续更新的内容工作台中检索、比较和复用。

它没有把核心价值停在“AI给出结论”，而是强调：

- 内容资产可检索。
- 一次采集后可以反复研究。
- 每个判断能回到原笔记。
- 图文、视频和博主主页使用不同表和视图。
- 飞书是工作台，AI是整理和拆解层。

## 3. 截图可确认的功能

### 3.1 输入

- 单条公开分享链接。
- 批量公开链接。
- 博主主页样本。
- 图文和视频链接。
- 页面宣称“不登录、不批量搜索、只处理用户主动提供的公开链接”。

### 3.2 基础采集

- 标题。
- 作者与博主主页信息。
- 封面图片。
- 正文。
- 标签。
- 点赞、收藏、评论、分享。
- 图片附件。
- 视频链接、时长和公开字幕。
- 来源链接与笔记ID。

### 3.3 图文拆解

截图展示的字段包括：

- 封面分析与图片分析。
- 互动诱因。
- 爆款/高表现原因。
- 可复制点。
- 内容主题与正文信息。

推断的产品逻辑是从“这篇写了什么”升级到“为什么值得研究、下一篇如何借鉴”。需要把“爆款归因”改写成“高表现解释假设”，避免公开快照被误当成因果结论。

### 3.4 视频拆解

- 标题与时长。
- 公开互动数据。
- 公开字幕或口播文案。
- 按时间点标记的开头、结构、节拍和结尾。
- 内容结构。
- 可复制的脚本模块。
- 无字幕时明确标注，不假装看过视频。

### 3.5 博主主页分析

- 账号定位。
- 高频选题。
- 内容形式。
- 标题与封面特征。
- 仅基于公开可见样本的边界声明。

### 3.6 飞书与本地资产

- 多维表格多视图。
- 图文库、视频库、博主库等分类。
- 链接、笔记ID、媒体缩略图和附件。
- 自动去重。
- 每次运行生成 Excel 备份。
- 失败条目保留原因。
- 卖家宣称可持续更新、后续迭代免费、赠送配置手册。

## 4. 竞品的用户旅程

`提供公开链接 -> 等待处理 -> 查看步骤状态 -> 自动入库 -> 按图文/视频/账号视图研究 -> 导出备份或继续使用飞书`

其体验优势来自三个“少”：

- 少输入：只交链接，不要求用户整理字段。
- 少等待：进度能被看见，结果自动进入固定位置。
- 少决策：图文、视频、账号、素材库分视图呈现。

## 5. 竞品的产品心理设计

### 信任

- 强调真实截图、来源链接、失败原因、Excel备份。
- 明确“只处理公开链接”。
- 不只给结论，还给原始字段和附件。

### 结果感知

- 使用“入库”“素材库”“内容资产”等词，而不是“爬虫”或“数据抓取”。
- 用表格和缩略图直接展示结果，用户能立刻判断是否值得继续。

### 低门槛

- 低价格、月卡不限次数、一键工作流。
- 把复杂能力包装成单个使用场景，而不是大量功能菜单。

### 边界

- 不承诺爆款增长。
- 明确无字幕时的缺失。
- 仅使用主动提供的公开内容。

## 6. 可借鉴与不可照搬

| 竞品思路 | 借鉴价值 | 我们的处理 |
|---|---|---|
| 公开链接直接输入 | 高 | 增加“粘贴单条/多条链接”入口 |
| 飞书多维表格作为研究库 | 高 | 优先优化字段、视图、去重和导入体验 |
| 图文/视频/账号分视图 | 高 | 研究库采用同类信息架构，但视觉不照抄 |
| 封面与附件呈现 | 高 | 显示封面缩略图；附件同步作为二期能力 |
| 单篇结构化拆解 | 高 | 定义明确字段，不把长报告当唯一结果 |
| Excel自动备份 | 高 | 每次采集保留可审计备份 |
| 失败原因可视化 | 高 | 研究库单独提供失败视图和重试 |
| 视频字幕/口播 | 中 | 有公开字幕才处理；无字幕必须明确缺失 |
| “爆款归因” | 中 | 改为“高表现解释假设” |
| 不登录、不搜索的定位 | 中 | 提供公开链接模式；已授权登录模式作为高级能力 |
| 极限低价月卡 | 低 | 先不跟随，需按服务成本和交付价值定价 |

## 7. 与我们现有能力的差距

| 能力 | 当前状态 | 目标状态 |
|---|---|---|
| 主页采集 | 已可采最多100篇及详情 | 保留，并增加链接模式 |
| 28列数据与表格导出 | 已有 | 作为基础资产保留 |
| 飞书导入文件 | 已有 | 增加预设视图、附加字段和使用说明 |
| 飞书直接同步 | 暂无 | 二期通过飞书 API/OAuth 或租户应用实现 |
| 单篇结构化拆解 | 主要散落在账号报告 | 建设独立“笔记拆解”表 |
| 图文封面分析 | 未处理图片内容 | 二期视觉分析，先显示封面和附件 |
| 视频字幕与时间轴 | 不支持 | 三期能力，需明确来源和失败状态 |
| 多任务统一检索 | 任务彼此独立 | 建设跨任务研究库和全局去重 |
| 去重与失败审计 | 单任务内已有基础 | 扩展为全局去重、运行记录和重试 |
| 账号对标 | 单批报告内分析 | 增加账号卡、横向比较和长周期新内容增量 |
| AI分析 | 已可生成深度报告 | 降为可选附加模块，建立单篇和账号两级输出 |

## 8. 竞争结论

竞品真正解决的是“用户想把看到的内容变成长期可研究的资产”。我们的采集深度和评论外数据边界并不比它弱，但当前交付中心放在长篇AI报告上，用户第一眼不容易理解核心价值。

新的竞争策略应是：

1. 保留更强的授权主页采集和完整正文能力。
2. 提供比竞品更透明的字段、失败和来源审计。
3. 把研究库与飞书导出放到主流程。
4. 把单篇拆解做成结构化行列，不用长报告代替。
5. AI账号报告作为可选的高客单交付，而不是默认首页。
