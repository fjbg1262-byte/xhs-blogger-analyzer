# 飞书内容研究工作台数据规范

## 1. 目标

用户在飞书中看到的不只是“导出的数据”，而是一套可持续研究的内容资产。

首期通过高质量导入文件实现；通过验收后再做飞书 API 直连。

## 2. 建议表结构

### 表1：账号库

| 字段 | 类型 | 说明 |
|---|---|---|
| 账号ID | 文本 | 平台用户ID |
| 账号昵称 | 文本 | 当前主页昵称 |
| 主页链接 | 超链接 | 去参数的主页地址 |
| 最近采集时间 | 日期 | 最近成功采集 |
| 本次笔记数 | 数字 | 去重后 |
| 正文覆盖数 | 数字 | 有正文的笔记 |
| 图文/视频数 | 两个数字字段 | 不做字符串拼接 |
| 公开互动总量 | 数字 | 赞藏评享合计 |
| 公开互动中位数 | 数字 | 单篇中位数 |
| 内容定位摘要 | 多行文本 | AI或人工确认 |
| 主要主题 | 多选 | 人工/AI归纳 |
| 研究状态 | 单选 | 待研究/研究中/已复盘 |

## 3. 飞书视图

至少预设或提供导入后设置指南：

1. 全部内容。
2. 图文笔记。
3. 视频笔记。
4. 高表现样本。
5. 最近采集。
6. 待拆解。
7. 拆解完成。
8. 采集失败。
9. 按账号分组。
10. 按主题分组。

## 4. 计数口径

- 公开互动 = 点赞 + 收藏 + 评论 + 分享。
- 缺失值保持空白，不补0。
- “高表现”按当前账号本批公开互动中位数定义。
- 不计算浏览率、互动率、点击率、ROI或完播率。
- 标签频次不等于搜索量或搜索流量。

## 5. 去重规则

优先级：

1. 平台笔记ID。
2. 去除跟踪参数后的笔记链接。
3. 用户手动覆盖。

重复记录不重复调用AI。更新只刷新允许变化的公开互动、正文、标签和采集状态，并记录更新时间。

## 6. 安全

- Cookie、API Key、飞书密钥不进入导出表。
- 飞书直连凭据保存在本机安全配置中。
- 日志不能记录完整 Cookie、密钥、私信或后台数据。
- 用户取消授权后停止同步并允许删除本地连接配置。

## 7. 验收

- 导入后首行就是字段名，可直接识别类型。
- 6张核心表均可独立导入或同步。
- 一行对应一个唯一内容对象。
- 去重后占比和失败原因可核对。
- 所有原文引用能回到来源笔记。
- 中文、长正文、换行、引号、链接和日期不损坏。
- 导入后的筛选、分组和视图可使用。
