## 核心决定

1. 产品核心不是“生成一份很长的AI报告”，而是**稳定采集公开内容、形成可搜索可筛选的研究库，并低成本进入飞书工作台**。
2. AI 分析是增值层，负责把原始内容和指标整理成可复用的单篇拆解、账号判断和选题建议，不替代数据采集与呈现。
3. 第一优先交付应是“笔记库/研究库”，而不是报告页。
4. 竞品值得借鉴的是低操作成本、字段结构化、飞书呈现、去重备份和持续沉淀；不应照搬无法证实的效率或爆款承诺。

## 当前与目标的差异

| 当前产品 | 目标产品 |
|---|---|
| 以主页整理和AI交付报告为主 | 以内容采集、研究库、飞书呈现为主，AI为附加能力 |
| 任务结束后查看单次结果 | 多批次内容资产持续沉淀、检索、比较 |
| 导出Excel/CSV/飞书导入文件 | 首先保证高质量导入文件，二期支持飞书多维表格直接同步 |
| 单篇主要看正文和互动 | 增加封面、内容结构、互动诱因、可复制模块等研究字段 |
| 账号报告较长 | 先给账号数据卡和结构化判断，深度报告按需生成 |
